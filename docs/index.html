So funktioniert's

    
    
      
  1. Foto auf die Seite ziehen oder auswählen.
    2. 
      
  2. Voreinstellung wählen (z. B. Vogelfoto) und bei Bedarf die Regler anpassen.
    3. 
      
  3. Vorschau rechnet nur einen Ausschnitt – schnell zum Ausprobieren. Ganzes Foto verarbeiten rechnet alles.
    4. 
      
  4. Mit dem Regler unter dem Bild Vorher/Nachher vergleichen, dann als PNG oder JPG herunterladen.
    5. 
    

    
Vogel-Modus

    
Die App sucht Vögel automatisch (KI-Erkennung) oder du ziehst selbst einen Rahmen um den Vogel. Der Vogel wird freigestellt, auf Arbeitsgröße gebracht (auch wenn er im Bild winzig ist), Federn werden herausgearbeitet, der Hintergrund stärker entrauscht und alles weich ins Foto zurückgesetzt.

    
Als App auf den Mac legen

    
Chrome: Adressleiste rechts → Installieren-Symbol, oder Menü ⋮ → „Speichern und teilen“ → „Seite als App installieren“.

    Safari: Menü „Ablage“ → „Zum Dock hinzufügen“.

    
Gut zu wissen

    
    
      
  • Alles läuft lokal in deinem Browser. Nichts wird hochgeladen. Beim ersten Start werden die KI-Bausteine (ca. 50 MB) aus dem Internet geladen.
    • 
      
  • Chrome nutzt, wenn möglich, deine Grafikkarte (WebGPU) – das ist deutlich schneller. Ohne WebGPU rechnet die App auf dem Prozessor, dann dauern große Fotos länger. Tipp: erst Vorschau, dann ganzes Foto.
    • 
      
  • Die Bearbeitung arbeitet mit 8 Bit pro Farbkanal. RAW-Dateien werden nicht direkt gelesen.
    • 
      
  • Sehr große Fotos (über ca. 40 Megapixel) können den Browser-Speicher sprengen – dann Vergrößerung auf 1× stellen oder das Foto vorher verkleinern.
